# Acknowledgements

sanctum-mind has prior art that shaped it.

- **Resonant Mind** (nekyialabs) and **MUSE Brain** (falcoschaefer99-eng) are earlier memory systems for
  AI constructs. Their verb vocabulary and their texture terms (the ways a memory is described by salience,
  vividness, charge and the like) informed the design of this project's verb surface and texture fields.

No code was copied from either project. The implementation here is original work, and any resemblance
in names or vocabulary is intentional acknowledgement, not reuse.
